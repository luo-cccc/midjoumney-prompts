# Midjourney 提示词助手

把角色概念、场景设定或参考图整理成可复制的英文 Midjourney 提示词，默认不生成图片。

## 统一视觉体系

默认采用同一个商业动画电影级三维世界：人物保持高级半写实 3DCG、精致二次元比例与高等级 BJD 的面部造型精度；环境保持电影级写实 3DCG 的空间、尺度、材质厚度和自然变化。

BJD 只表示面部设计精度和理想化比例，不表示陶瓷皮肤、玻璃眼睛、人偶关节或玩具材质。人物可以比环境更理想化，但同框时要共享主光方向、环境反射光、材质响应、曝光、白平衡、透视、景深和电影调色。

这是一套目标观感，不是对 Midjourney 渲染引擎或物理管线的配置承诺。提示词只选择与画面相关的造型、材质和融合描述，不整段堆砌技术名词。

## 四种工作流

| 用途 | 默认表现与构图 | 默认 CG 参数 |
| --- | --- | --- |
| 角色设计 | 理想化半写实 3DCG；头到腰的半身像 | `--ar 3:4 --raw --s 150` |
| 角色设定图 | 相同角色体系；白底棚拍光；左侧无头全身三视图，右侧四格头肩特写 | `--ar 16:9 --raw --s 150` |
| 场景设计 | 电影级写实 3DCG；平视宽景；角色入景时保持理想化造型与统一渲染 | `--ar 16:9 --raw --s 150` |
| 可控扩图 | 保留原图实际画风、比例、镜头和已有内容，只完成裁切结构 | 不固定参数，不自动转成 CG |

`--raw --s 150` 是统一比较用的起始预设，不是 CG 画风的必要条件或效果保证。用户明确指定的参数和比例优先。设定图使用棚拍光，叙事场景按时间、天气和环境组织光照。

## 画风优先级

1. 本次请求明确指定的画风、媒介和参数。
2. 本次没指定时，沿用用户为相关角色或世界观明确选择过的画风。
3. 都没有时，使用统一 3DCG 默认体系。接受工作流默认值、单独附上角色图，不等于要求沿用该图的绘画媒介。

绘画、动漫插画、水彩和水墨仍可明确请求；它们替换默认 CG 描述，不附加 BJD、PBR、次表面散射等词。替代媒介沿用与之关联、已经确认的 `--raw`、`--s`；没有时不额外指定。场景和设定图按自身需求决定比例，不照搬角色半身像的 3:4。

同框时“人物更理想化、环境更写实”属于统一 CG 体系的预期差异，不需要强行把两者改成相同写实程度，也不应当成画风冲突提醒。旧的默认绘画图被用作新 CG 场景的身份参考时，助手会简要说明媒介变化与参考图的潜在影响。

修订保留已确认画风，除非要求改变；扩图始终延续原图实际媒介。把水墨图扩展为更大水墨图，与把水墨图改成 CG，是两个不同任务。

## 角色与场景一致性

- 角色入景时，写清位置、大小，以及与地面、家具或道具的接触关系；使用环境的光线和色彩反射，避免抠图感。
- 角色未设计的下装和鞋履优先取自设定图，否则保守推断并标明。设定图也会说明新增的服装推断；推断不等于已确认设计。
- 有角色图时，在支持的界面中附到 `Attach to prompt`。尚未生成时，先使用角色设计提示词生成，再附图。保留本次构图的 `--ar`。
- 参考图可能带入原有风格；文字不能保证完全分离身份与画风。Midjourney 编辑模型和参数支持可能随版本改变。
- `--no` 作用于整张图：有角色时不能排除 `people`；设定图右侧有头发，不能全局排除 head 或 hair。优先正面描述，只列必要的具体排除项。

## 使用示例

- 角色：`成年精灵游侠，银发，苔绿色斗篷，使用统一的高级半写实 3DCG 人物体系。`
- 设定图：`根据这个角色做三视图和头部特写，保持脸型与服装，材质使用同一套 CG 体系。`
- 场景：`黄昏的树屋村落，电影级写实 3DCG 环境，不要人。`
- 同框：`让她站在村口，场景为主体，保留精致半写实脸型，用左侧夕阳和环境反射光把她融入真实材质的村落。`
- 替代媒介：`湖边船屋，清晨薄雾，水彩风，横版 16:9。`
- 扩图：`保留这张水墨图的笔触，只补全被裁掉的斗篷和手臂，不扩成全身。`

## 文件与安装

- `SKILL.md`：入口、工作流路由和通用规则。
- `agents/openai.yaml`：界面名称、简介与调用示例。
- `references/visual-system.md`：共享视觉体系、参数与同框融合规范。
- `references/character-design.md`：角色设计。
- `references/reference-sheet.md`：角色设定图。
- `references/scene-design.md`：场景设计。
- `references/outpainting.md`：可控扩图。

解压后保留顶层 `midjourney-prompts/`，将整个目录放入宿主支持的技能目录；ZCode 可使用项目或用户级 `.agents/skills/`。ZIP 是分发包，能否直接上传由宿主界面决定。

## 打包与验证

`midjourney-prompts.zip` 包含以上七个技能文件与本说明，共八个文件，统一置于顶层 `midjourney-prompts/`。不包含 `.git`、备份、缓存、临时脚本、测试输出或压缩包本身。

验证覆盖规则审查、模拟提示词输出、YAML、内部链接和压缩包完整性。模拟测试只能检查文字和规则执行；真实皮肤、人物环境融合、多视图一致性、精确文字和参考图影响，仍需实际出图验证。
