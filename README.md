# Midjourney 提示词助手

把角色概念、场景设定或参考图整理为可直接复制的英文 Midjourney 提示词。技能本身输出文本，不负责生成图片。

## 四种工作流

| 用途 | 默认画风与构图 | 默认参数 |
| --- | --- | --- |
| 角色设计 | 半写实动漫绘画；头到腰的半身像 | `--ar 3:4 --raw --s 150` |
| 角色设定图 | 半写实游戏 CG；左侧无头全身三视图，右侧四格头肩特写 | `--ar 16:9` |
| 场景设计 | 半写实游戏 CG；平视宽景，突出一个视觉焦点 | `--ar 16:9` |
| 可控扩图 | 保留原图画风、比例与镜头，只补全被裁切的结构 | 依据原图和编辑方式，不固定参数 |

用户明确要求的比例、画风和参数优先于默认值。省略 `--raw` 或 `--s` 会使用 Midjourney 账号设置，不能保证不同账号的结果一致。

## 场景画风怎么选

1. 优先使用本次场景明确要求的画风。
2. 本次没指定时，沿用用户曾为相关角色或世界观明确选择的画风。
3. 用户从未选过画风时，默认用游戏 CG。接受默认动漫角色设计、附上其图片，都不会自动把场景改成绘画风。

要求普通“绘画风”时使用半写实动漫环境绘画，参数为 `--ar 16:9 --raw --s 150`。水彩、水墨等具体媒介使用各自描述，不混入游戏 CG 或动漫绘画词。已有该媒介的参数时沿用 `--raw`、`--s`；没有时不额外指定。宽高比始终按场景需求决定，不照搬角色半身像的 3:4。

场景如果从角色默认绘画风切换为游戏 CG，会附一句说明。角色未设计的下装和鞋履优先取自设定图，否则作合理推断并标明；推断内容仍需用户确认。角色设定图本身默认游戏 CG，如需同样的水彩或水墨风，请明确说明。

## 使用示例

- 角色：`设计一位守护古森林的成年精灵游侠，银发，苔绿色斗篷。`
- 设定图：`根据这个角色做三视图和头部特写，保持服装和面部一致。`
- 场景：`设计黄昏的树屋村落，游戏 CG 风，不要人。`
- 指定媒介：`湖边船屋，清晨薄雾，水彩风，横版 16:9。`
- 角色入景：`让这个角色站在村口，场景为主体，保留她的服装和配色。`
- 扩图：`只补全被裁掉的斗篷和手臂，保持头部大小，不扩成全身。`

有角色参考图时，在支持的 Midjourney 界面中将其附在 `Attach to prompt`，保留场景的 `--ar`。参考图能帮助保持身份，但仍可能影响画风；文字提示不能保证完全隔离其影响。编辑模型与参数支持可能随 Midjourney 版本改变。

正文以正面描述为主；必要排除项使用简短的 `--no` 列表。`--no` 作用于整张图，不应用它排除其他区域仍需要的头、头发或人物。

## 文件说明

- `SKILL.md`：技能入口、工作流路由和通用规则。
- `agents/openai.yaml`：界面名称、简介与调用示例。
- `references/character-design.md`：角色设计。
- `references/reference-sheet.md`：角色设定图。
- `references/scene-design.md`：场景设计与画风选择。
- `references/outpainting.md`：可控扩图。

解压后保留顶层 `midjourney-prompts/` 目录。将整个目录放入宿主支持的技能目录；ZCode 可使用项目或用户级 `.agents/skills/`。ZIP 是分发包，是否支持直接上传以宿主界面为准。

## 打包与验证

分发包名为 `midjourney-prompts.zip`，包含以上六个技能文件与本说明，共七个文件，统一置于顶层 `midjourney-prompts/` 下。排除备份、临时脚本、缓存、测试输出以及压缩包本身。

已完成工作流选择和提示词输出的模拟测试，以及结构、YAML、内部链接和压缩包完整性校验；没有在 Midjourney 实际生成图片。多视图一致性、画面布局、精确文字和参考图影响仍需出图确认。
