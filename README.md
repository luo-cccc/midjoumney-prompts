# Midjourney 提示词助手

把角色概念、场景设定或参考图整理成可复制的 Midjourney 提示词，并支持 GPT-image2 非重要角色直出设定图，以及基于MJ场景底图的一致性变更提示词。默认输出文本，不生成图片；MJ 默认英文，GPT-image2 沿用用户指定语言或当前请求语言。

## 工作流与默认值

| 用途 | 默认表现 | 默认参数 |
| --- | --- | --- |
| 角色设计 | 半写实动漫绘画，头到腰的半身像 | `--ar 3:4 --raw --s 150` |
| 角色设定图 | 带 CG 体积感的半写实数字绘画，白底三视图与四格头像 | `--ar 16:9 --raw --s 150` |
| 非重要角色直出设定图（GPT-image2） | 从文字设计新角色，重要角色设定图提供画风参考；沿用三视图与四格头像 | 自然语言描述横版16:9，不附加MJ参数 |
| 场景首张底图（MJ） | 电影级写实 3DCG 环境；人物入景时保留理想化三维造型 | `--ar 16:9 --raw --s 150` |
| 场景一致性变更（GPT-image2） | 以已有底图或指定版本编辑，保留场所结构与实际画风 | 自然语言说明保持项与变化项，默认沿用底图画幅 |
| 可控扩图 | 保留原图实际画风、比例和镜头，仅补全裁切结构 | 依原图与编辑方式，不固定参数 |

MJ参数是起始预设，不保证特定媒介或物理渲染效果。未指定参考画风时，设定图使用中性略冷的棚拍光；匹配参考画风时按实际参考组织光照。场景按环境、时间和天气组织光照。人物使用自然面部结构与材质表现，不以人偶美学为设计目标。

## 画风与参考图

- 本次明确指定的画风、比例和参数优先；否则沿用用户为相关角色或世界观明确选择过的画风，最后才使用工作流默认值。
- 接受某工作流的默认画风或单独附图，不自动改变另一工作流的默认。明确要求匹配原图画风时才沿用。
- 水彩、水墨等替代媒介不混入 PBR、次表面散射等 CG 描述。沿用与该媒介关联的已确认 `--raw`、`--s`；没有时不额外添加。当前工作流决定默认画幅，不照搬旧肖像的比例。
- 修订保留已确认画风，扩图延续原图实际媒介。CG 场景允许人物比环境更理想化，但光照、透视、材质响应和调色需一致。
- 目标角色的身份图提供身份、服装和配色；单独的布局或风格参考仅提供指定用途。附图可能影响媒介表现，文字不能保证完全隔离。

## 设定图直接生成

直接使用当前肖像、扩图或全身图生成一张完整设定图，不强制增加认可图、分视角生成或拼装环节。

明确为非重要角色、次要角色的设计请求，默认走 GPT-image2 直出设定图；明确要求 MJ 或半身像时遵从本次要求。不根据职业、种族、年龄或外貌判断角色重要性。

默认格式为左55%正、侧、背三视图，右45%正面、45度、侧面和正脸近景四格头像。左侧每个人物保留包含头部空间的展示区域，隐藏头部后上方留白；颈下身体保持尺度，只通过统一缩放和间距适应版面。头发仅在左侧服装展示中隐藏，披风等衣物保留。右侧头像放大只改变展示倍率，不改变内在头颈肩关系。

从目标角色图生成时，组装顺序为：身份和可见体型依据 → 保守补全 → 画布与分区 → 左侧占位与三视图 → 右侧头像 → 当前角色的脸、服装、配色和材质 → 质感与MJ参数。具体脚本骨架见 [设定图规则](references/reference-sheet.md)。文字直出使用下文的GPT-image2分支。

腰带、裙长和画布长度不等于人体腰线或腿长。不可见人体、背面和鞋履可保守推断并简要标明，不宣称精确恢复。性别、年龄、体型、肢体、发型与服饰按角色提取，不套固定几头身、五指或示例配色。

## 非重要角色：GPT-image2直出

输入为“新角色文字设定＋重要角色设定图作为画风参考”，直接输出一条完整设定图提示词，省去先设计肖像、扩图和确认全身图的环节。若已有目标角色图，可另标为身份参考。

重要角色图仅提供明确指定的媒介、造型风格、笔触、体积塑造、材质表现、光照和色彩处理。新角色的脸、体型、发型、服装结构和专属配色从文字与世界观设计；同阵营制服或纹样按明确要求继承。仅参考画风不自动复制参考图版式，默认仍用本技能的三视图与四头像布局。非重要角色保持相同绘制完成度，装饰复杂度按身份与需求决定。

转换保留原MJ设定图的布局、比例、服装一致性与分区显示规则，将画幅与排除项改成自然语言，删除 `--ar`、`--raw`、`--s`、`--sref`、`--no` 等MJ语法，不虚构GPT-image2参数。未收到参考图时不宣称已提取画风。具体规则与提示词骨架见 [GPT-image2设定图](references/gpt-image-sheet.md)。

## 场景：MJ底图到GPT-image2变更

1. 首张底图使用MJ场景提示词，确定地标、建筑道路关系、地形、材质和镜头。已有文字草案、还未出图时的修改仍属于这一阶段。
2. 底图产生后，后续默认输出GPT-image2编辑提示词，以用户指定的底图或当前版本为场景依据，修改时间、天气、季节、人物、道具或局部状态。明确要求其他引擎时遵从本次要求。

同机位变更保留建筑结构、道路与地标位置、尺度、透视、构图和实际画风；变化所需的光照、阴影、反射、遮挡和地表状态同步调整。例如雨夜版本保持同一个村落，但允许窗灯、倒影、湿地面和夜间明暗变化。

新增人物不自动删除场景原有的人群；已有标识与招牌在未要求移除时保留。明确用MJ修订已有场景时也继承这些内容和场景原画幅，不重新套用新底图的无人、无文字或16:9默认。扩画幅保持原图区域的尺度与透视，允许其占新画布的比例改变，不为保持占比而缩放原内容。

独立的昼、夜、雪景变体分别从指定底图出发；连续剧情如“在刚才雨景里加人”沿用所选雨景版本。原始底图可补充结构依据，但不能覆盖已确认的剧情变化。明确要求新机位时保持空间连接与建筑设计，允许构图和屏幕位置变化；新露出的结构保守补全并说明。缺少原图时可先写文字草案，不宣称已核对图像。具体规则见 [GPT-image2场景变更](references/gpt-image-scene.md)。

## 一致性与局部修正

- 保留已确认的设计和明确移除的物件；返图新增内容只有用户采纳后才作为后续依据。
- 单图的衣摆、表情、装饰或裁切修正不自动成为通用默认。服装长度、拖尾和细节密度按设计决定。
- MJ的 `--no` 作用于整张图。不要排除其他区域仍需要的人物、头发或衣物；必要排除项保持具体、简短。GPT-image2用自然语言限定到相应分区。
- 角色入景使用共同光照、环境反射光、透视和接触阴影。MJ附图放入支持界面的 `Attach to prompt`，保留本次 `--ar`；GPT-image2分别标明场景编辑图与角色身份图的用途。已有参考时不要求重新生成角色图。

## 使用示例

- 角色：`成年精灵游侠，银发，苔绿色斗篷，半写实动漫绘画。`
- 设定图：`根据这张扩图生成设定图，保留角色设计，使用默认布局与数字绘画质感。`
- 非重要角色：`设计一位次要角色，成年人类驿站管理员，深棕短发，靛蓝工作外套和皮革腰包。直接给我GPT-image2设定图提示词，参考附件重要角色设定图的画风，使用默认三视图与四头像布局。`
- 场景：`黄昏的树屋村落，电影级写实3DCG，不要人。`
- 场景变更：`基于这张MJ村落底图，给我GPT-image2雨夜版提示词，保留机位与建筑道路结构，亮起已有窗户的灯光。`
- 连续变更：`在刚才确认的雨夜版本中，按角色设定图把她放在桥头，保留雨夜状态和村落结构。`
- 同场景换机位：`参考这张底图，从桥头看向水车，保持建筑形制与空间连接，使用GPT-image2。`
- 同框：`让她站在村口，场景为主体，保留角色造型，用夕阳和环境反射光融合人物。`
- 替代媒介：`湖边船屋，清晨薄雾，水彩风，横版16:9。`
- 扩图：`保留水墨笔触，只补全被裁掉的斗篷和袖口，不扩成全身。`

## 文件与安装

- `SKILL.md`：入口、工作流选择和通用输出规则。
- `agents/openai.yaml`：界面名称、简介和调用示例。
- `references/visual-system.md`：共享画风优先级、参数和CG表现规范。
- `references/character-design.md`：角色设计。
- `references/reference-sheet.md`：设定图组装规则和通用骨架。
- `references/gpt-image-sheet.md`：非重要角色直出GPT-image2设定图、参考图分工与MJ逻辑转换。
- `references/scene-design.md`：MJ场景首张底图与人物入景。
- `references/gpt-image-scene.md`：基于已有场景的GPT-image2一致性变更、版本衔接与换机位。
- `references/outpainting.md`：可控扩图。

解压后保留顶层 `midjourney-prompts/`，放入宿主支持的技能目录。ZCode 可使用项目或用户级 `.agents/skills/`；是否支持直接上传ZIP由宿主决定。

## 分发与验证

`midjourney-prompts.zip` 包含九个技能文件和本说明，共十个文件，不包含 `.git`、备份、缓存、测试输出或压缩包本身。

文本模拟与结构检查只能验证规则执行、YAML、链接和包内容，不能证明成图的头身比、身份、多视图一致性或精确文字。实际效果仍需出图判断。
